# 字体资产

Inter（内部版本4.001;git-66647c0bb）：Regular 400、SemiBold 600、Bold 700、Italic 400。JetBrains Mono（内部版本2.211）：Regular 400、Italic 400。

六款WOFF2共161172 bytes，字体二进制未修改。CSS字族别名不更改字体或表示作者背书。中文等字符由系统字体回退，不承诺跨平台字形相同；未提供500实体字重，浏览器按可用字重匹配。

构建将字体内嵌为data URL，Base64载荷214904 bytes，免网络依赖。字体原文件仍是重建和许可审计必需文件，不因CSS已内嵌而删除。不打包Anthropic专有字体。

字体适用[SIL OFL 1.1及版权声明](licenses/OFL-1.1.txt)，不受根目录MIT替代。
