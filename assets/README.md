# 字体说明

本插件不内嵌字体文件，也不联网加载字体，所有字形均来自系统或用户本机已安装的字体：

- **UI**：`system-ui` / `Segoe UI` / `PingFang SC` / `Microsoft YaHei UI`
- **正文阅读**：优先匹配本机已安装的开源衬线（`Source Serif 4`、`Newsreader`、`Literata`、`Noto Serif SC`、`Source Han Serif SC`），未安装时回落至系统人文衬线
- **代码块**：`Cascadia Code` / `ui-monospace` / `SFMono-Regular` / `Consolas`

不存在需随包分发的第三方字体许可。
