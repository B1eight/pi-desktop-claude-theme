# 字体资产

Inter（内部版本4.001;git-66647c0bb）：Regular 400、SemiBold 600、Bold 700、Italic 400。JetBrains Mono（内部版本2.211）：Regular 400、Italic 400。

各字重已内嵌到主题 CSS，无需联网加载。中文等字符由系统字体回退，不承诺各平台字形一致；未提供 500 字重，浏览器按可用字重匹配。

字体源文件用于重建主题和核对许可，因此与内嵌产物一并保留。CSS 字族别名只影响字体匹配，不表示字体作者为本项目背书。不打包 Anthropic 专有字体。

字体适用[SIL OFL 1.1及版权声明](licenses/OFL-1.1.txt)，不受根目录MIT替代。
